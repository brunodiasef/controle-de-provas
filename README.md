# Controle de Provas

App para controlar as provas das turmas: data, confirmação de aplicação, faltosos e relatório geral.

Abra o link do GitHub Pages no celular ou no computador e use "Adicionar à tela inicial" / "Instalar app".
No primeiro uso, carregue o arquivo `turmas.json` com a lista de alunos (ele não fica no repositório; os nomes ficam guardados só no aparelho).
